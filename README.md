## 🏗️ What I've been building

### Pharmacy Procurement & Automation Platform · *Sahl Pharma · team of 3*
- Internal procurement platform built on **Clean Architecture + Modular Monolith + CQRS**, with automated tests
- Arabic text-normalization and product-matching pipeline that reconciles price lists from **130+ suppliers** against the ERP catalog, cutting matching time by **~90%** with in-memory processing and indexing
- Automated purchasing recommendations as **Hangfire** background jobs, ranking supplier offers by stock urgency, price and payment terms, plus Reverse-FIFO debt-aging and vendor-credit calculations
- Keyboard-first Angular purchasing UI, refined through direct client feedback

### B2B Pharmacy Ordering Platform · *Sahl Pharma*
- Ordering platform for retail pharmacies with tiered pricing and invoice-level quotas
- **Concurrency-safe stock reservations** using PostgreSQL row-level locking and serializable transaction retries
- Real-time order updates pushed through **SignalR**

### EduFlowAI: AI-Powered Admission Platform · *ITI graduation project · team of 8*
- Modular admission platform covering applications, document management, eligibility checks and applicant ranking, with **RabbitMQ**-based background processing
- AI-assisted document verification against applicant data, with human review for uncertain cases
- Bilingual Arabic/English **RAG assistant** grounded in institutional documents

<sub>These are client and team codebases, so the source isn't public. Happy to walk through the architecture in an interview.</sub>
